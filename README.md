# Goldbot · ساختار بازار

ربات تلگرام که **فقط ساختار بازار** را نشان می‌دهد: اسپایک، کانال یا رنج، روی آخرین ۵۰۰ کندل.
بدون هشدار، معامله یا بک‌تست. نسخه‌های قبلی (هشدار، معامله، بک‌تست) در تاریخچه‌ی git هستند.

## استفاده
- `/start` یا دکمه‌ی **📐 Structure** پایین چت
  1. جفت: طلا، ۷ ماژور (EURUSD، GBPUSD، USDJPY، USDCHF، USDCAD، AUDUSD، NZDUSD) و داوجونز (US30)
  2. تایم‌فریم: M1، M5، M15، M30، H1، H4، D1
  3. دو عکس: آخرین ۵۰۰ کندل با ساختار، و بزرگ‌نمایی دو ساختار آخر؛ دکمه‌های 🔄 تازه کردن، ⏱ تایم‌فریم، 📐 جفت دیگر
  4. **🔬 M1 + M5 + گپ** (دکمه‌ی زیر تایم‌فریم‌ها): کندل‌های M1 (خاکستری، حداکثر ۴۸۰ کندل) روی زمینه‌ی سفید (`bot/mtf.py`):
     هر ساختار M5 یک جعبه‌ی آبی کم‌رنگ (رنج صاف، کانال مورب) با قیمت سقف و کفش؛ روی M1 **ستاپ گپ** (`bot/gap.py`):
     جعبه‌ی گپ (نارنجی فروش، فیروزه‌ای خرید)، ورود (مثلث)، حد ضرر و حد سود ۱:۱ (خط‌چین)، خروج (دایره‌ی سبز/قرمز).
     چرخه‌های ریز M1 (نسخه‌ی ۱) هنوز در کد هست (`layer="micro"`) ولی فعلاً نشان داده نمی‌شود.
- **🧪 Gap backtest** (دکمه‌ی پایین چت، زیر تایم‌فریم‌های هر جفت، یا `/backtest XAUUSD 5`): جفت (طلا، ماژورها، داوجونز) ← تایم‌فریم
  **M1، M5 یا M15** ← ستاپ گپ روی **۳ روز معاملاتی اخیر** اجرا می‌شود (`bot/gap_backtest.py`): تعداد معامله، برد/باخت،
  جمع R، خریدها و فروش‌ها جدا، حساب ۱۰۰۰ دلاری با ریسک ۱٪ و ۲٪ و افت حداکثر، آخرین معامله‌ها (شماره‌دار، وقت تهران)،
  و نمودار موجودی. بدون اسپرد. روی **M1**، بعد از گزارش برای هر معامله‌ای که **حد ضرر خورد** یک عکس بزرگ‌نمایی‌شده
  (`bot/gap_pictures.py`، آلبوم‌های ۱۰تایی): کندل‌های M1 دور معامله، جعبه‌های ساختار M5 همان لحظه (از ۵۰۰ کندل M5 تا ورود)،
  جعبه‌ی گپ با کندل ۱ و ۳، ورود، حد ضرر، حد سود و خروج.
- میان‌بر: `/structure EURUSD 5` (تایم‌فریم: `1`، `5`، `15`، `30`، `60`، `240`، `D`) یا `/structure XAUUSD mtf`

## قاعده‌ی ساختار (`bot/structure3.py`)
- فقط قیمت بسته‌شدن (مثل نمودار خطی)؛ سایه‌ها کف و سقف نمی‌سازند. کف و سقف یعنی برگشت حداقل ۱۰٪ ارتفاع نمودار
- هر لحظه یکی از سه حالت: 🚀 اسپایک (پایه‌ی تند و صاف)، 📈/📉 کانال (سقف و کف بالاتر یا پایین‌تر)، 📦 رنج (هر چیز دیگر؛ می‌تواند مثلثی باشد)
- رنج تا بریک‌اوتی که برنگردد ادامه دارد؛ بیرون‌زدنی که برگردد (حتی ریزش یا جهش تند) جزو رنج است
- کانالی که رنجِ بعدش کامل پسش بگیرد فقط یک پایه‌ی رنج بوده
- خط‌ها: لبه‌های رنج (افقی، یا مثلثی اگر به هم نزدیک یا دور شوند)؛ کانال: خط روند از دو سقف/کف + خط موازی
- آخر نمودار موقت است و با کندل‌های بعدی ممکن است عوض شود. اگر آخرین بسته‌شدن از آخرین کف کانال صعودی (یا سقف کانال نزولی) رد شده باشد، پایه‌ی آخر جدا و در جهت جدید برچسب می‌خورد

## فایل‌ها
| فایل | کاربرد |
|---|---|
| `bot/data.py` | دریافت کندل از TradingView |
| `bot/structure3.py` | تشخیص ساختار و رسم عکس |
| `bot/mtf.py` | عکس M1 با ساختار M5 و ستاپ گپ |
| `bot/gap.py` | ستاپ گپ روی M1 |
| `bot/gap_backtest.py` | بک‌تست ستاپ گپ (M1 / M5 / M15، ۳ روز اخیر) |
| `bot/gap_pictures.py` | عکس بزرگ‌نمایی‌شده‌ی هر معامله‌ی بازنده با ساختار M5 |
| `bot/structure.py` | تشخیص ریز نسخه‌ی ۱ (برای چرخه‌های M1) |
| `bot/telegram_bot.py` | دکمه‌ها و دستورها |
| `bot/config.py` | نمادها و تایم‌فریم‌ها |
| `bot/main.py` | نقطه‌ی شروع (وب‌سرور Render + تلگرام) |

## متغیرهای محیطی (Render → Environment)
| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از BotFather (ضروری) |
| `STRUCTURE_PAIRS` | اختیاری: فهرست نمادها، پیش‌فرض `XAUUSD,EURUSD,GBPUSD,USDJPY,USDCHF,USDCAD,AUDUSD,NZDUSD,US30` |
