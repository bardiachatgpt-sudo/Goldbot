# Goldbot 🥇

ربات تلگرامی معامله با **پرایس اکشن ال بروکس**، برای طلا، ماژورهای فارکس و بیت‌کوین.
**زمینه روی ۵ دقیقه** (اسپایک، کانال، رنج) و **ماشه روی ۱ دقیقه** (ورود). داده از وب‌سوکت TradingView.

- منطق پایه‌ی تشخیص (EMA20، نوع کندل، سوئینگ، H1/H2، وج): از ریپازیتوری `price-action-skills-albrooks`
- اتصال به داده: همان روش `BardiaqTradingbot`

## نمادها
🥇 XAUUSD · 🇪🇺 EURUSD · 🇬🇧 GBPUSD · 🇯🇵 USDJPY · 🇨🇭 USDCHF · 🇨🇦 USDCAD · 🇦🇺 AUDUSD · 🇳🇿 NZDUSD · ₿ BTCUSD

برای تغییر فهرست، `SYMBOLS` را در `bot/config.py` ویرایش کنید.

همه‌ی اندازه‌ها نسبت به میانگین اندازه‌ی ۲۰ کندل قبلی همان نماد و همان تایم‌فریم سنجیده می‌شوند.

## ۱. تعریف کندل‌ها
| کندل | تعریف |
|---|---|
| Trend bar | بدنه ≥ ۵۰٪ کندل، بسته‌شدن در ربع انتهایی |
| Key bar | Trend bar با اندازه ≥ ۱.۲ برابر میانگین، بسته‌شدن نزدیک انتها |
| پین‌بار | سایه ≥ ۶۰٪ کندل، اندازه ≥ ۰.۸ برابر میانگین |
| ↳ پین‌بار رنج | کف یا سقف ۱۰ کندل اخیر را رد کرده |
| ↳ پین‌بار پولبک | کف یا سقف ۳ کندل اخیر را رد کرده |

## ۲. چرخه‌ی بازار روی M5
نمودار مثل خود ال بروکس از چپ به راست خوانده می‌شود. وضعیت هر لحظه فقط از گذشته ساخته می‌شود و بعداً عوض نمی‌شود.

| حالت | تشخیص | پایان |
|---|---|---|
| 📦 **رنج** | حالت پیش‌فرض و هر جای مبهم (اگر شک داری، رنج است) | اسپایکی که بیرون سقف یا کف رنج بسته شود |
| 🚀 **اسپایک** | یک Trend bar ≥ ۲ برابر میانگین، یا دو Trend bar پشت‌سرهم که هر کدام فراتر از کندل قبلی بسته شوند، بیرون محدوده‌ی ۱۰ کندل اخیر | اولین پولبک ← کانال |
| 📈 **کانال** | **خط روند اصلی** از شروع کانال (کف اولین پولبک)، طوری که همه‌ی کندل‌ها یک طرفش بمانند (دو نقطه لازم دارد)، و **خط کانال** موازی آن. **تنگ:** بدون بسته شدن آن طرف EMA و پولبک‌های حداکثر ۳ کندلی. **باز:** بقیه | بسته‌شدن آن طرف خط روند اصلی ← کانال در حال تست |
| ⚠️ **کانال در حال تست** | شکستن خط روند به‌تنهایی پایان کانال نیست؛ تست سقف تصمیم می‌گیرد | بسته‌شدن بالای سقف و نگه‌داشتنش ← کانال ادامه دارد (بازتر). Double Top (حتی Higher-High)، Lower High یا ۲۰ کندل بدون سقف تازه ← رنج |

- **پولبک:** پولبکی که زیر شروع اسپایک بسته شود ← رنج (اسپایک پاک شد). اگر ۲۰ کندل بگذرد و سقف تازه ساخته نشود هم ← رنج.
- **اسپایک مخالف:** یک اسپایک قوی مخالف در هر حالتی ← اسپایک مخالف.
- **احتمال برگشت:** در رنجی که بعد از تست آمده، اگر کف شکست هم شکسته شود ← «احتمال برگشت».
- **هدف احتمالی:** شروع آخرین کانال در رنج نشان داده می‌شود (ال بروکس: معمولاً دوباره تست می‌شود).

## ۳. ورود به معامله (روی M1)
| | 📦 رنج | 🚀 اولین پولبک بعد از اسپایک |
|---|---|---|
| زمینه M5 | رنج | اسپایک (کندل وحشتناک) از رنج بیرون زده و الان **اولین پولبک** است |
| شرط پولبک | — | روی M5 به داخل رنج قبلی (آن طرف سطح شکسته‌شده) بسته نشده، و سقف اسپایک هنوز رد نشده (حداکثر ۲۰ کندل M5) |
| سیگنال M1 | پین‌بار رنج در **ربع پایینی** رنج M5 (خرید) یا **ربع بالایی** (فروش) | پین‌بار پولبک در جهت اسپایک که آن طرف سطح شکسته‌شده بسته شود |
| ورود | **Buy Stop روی سقف پین‌بار** (Sell Stop روی کف)، حداکثر ۳ کندل | **Key bar** در همان جهت تا ۳ کندل بعد؛ ورود با شروع کندل بعد از Key bar |
| لغو | عبور قیمت از سایه‌ی پین‌بار قبل از ورود، یا تمام شدن ۳ کندل | همان |
| حد ضرر | پشت سایه‌ی پین‌بار ± اسپرد | همان |
| حد سود | ریسک × ۲ (اگر از لبه‌ی مقابل رنج رد شود، با هشدار) | ریسک × ۲ |
| تعداد | — | فقط یک ورود برای هر اسپایک |

یک معامله در هر لحظه برای هر جفت.

**ترتیب رسیدن قیمت به ورود، سایه، حد ضرر و حد سود:**
- **روش اصلی:** وقتی سفارش رنج یا معامله‌ی باز داریم، ربات به **قیمت زنده** TradingView گوش می‌دهد و همان لحظه تصمیم می‌گیرد و پیام می‌دهد.
- **پشتیبان:** اگر قیمت زنده قطع بوده، ترتیب از شکل کندل M1 حدس زده می‌شود. صعودی: باز ← کف ← سقف ← بسته. نزولی: باز ← سقف ← کف ← بسته.

**اسپرد:** فعلاً عددهای پیش‌فرض (طلا 0.30، EURUSD 1.2 پیپ، BTC 15، ...). با `SPREAD_<نماد>` در Render عوض می‌شود. اسپرد فقط به حد ضرر اضافه می‌شود.

گزارش نتیجه (+2R یا −1R) برای اطلاع و آمار است؛ نتیجه‌ی واقعی را بروکر تعیین می‌کند.

## ۴. پیام‌ها
| پیام | برای |
|---|---|
| 🎯 ستاپ ← 🚀 ورود ← 🏆 حد سود / 🛑 حد ضرر، یا ✖️ لغو | همه‌ی کاربران و کانال |
| 🚀 اسپایک M5 از رنج بیرون زد، منتظر اولین پولبک باشید | همه‌ی کاربران و کانال |
| 🔄 هر تغییر چرخه‌ی M5 (رنج / اسپایک / کانال / تست / ادامه / احتمال برگشت) | فقط کسانی که آن جفت را ⭐ فالو کرده‌اند |
| هشدارهای اطلاعاتی M5: H2/L2، پین‌بار M5، وج | پیش‌فرض خاموش (با `ALERT_SETUPS` روشن می‌شوند) |

**هر پیام یک عکس از همان لحظه دارد:**
- کندل سیگنال پررنگ و برچسب‌خورده، Key barها با قاب زرد، پین‌بارها با برچسب PIN
- عکس‌های معامله: نمودار M1 با خطوط ورود، حد ضرر و حد سود، سطح شکسته‌شده یا محدوده‌ی رنج، و پین‌بار و Key bar علامت‌خورده
- عکس‌های چرخه: نمودار M5 با بخش‌های چرخه، خط روند اصلی و خط کانال

## ۵. تلگرام
- `/start`: ثبت‌نام و دکمه‌ی همه‌ی جفت‌ها (جفت‌های فالوشده با ⭐)
- دکمه‌ی هر جفت یا `/status XAUUSD`: وضعیت چرخه‌ی M5 با سطح‌ها، گزارش و نمودار، به‌همراه دکمه‌های ⭐ Follow / 🔕 Unfollow، 🔄 Refresh و 📋 All pairs
- `/follow XAUUSD`، `/unfollow XAUUSD`، `/following`
- **🧪 Backtest** (دکمه زیر فهرست جفت‌ها، یا `/backtest`): مرحله‌به‌مرحله
  1. جفت‌ارز (پیشنهاد: طلا)
  2. تایم‌فریم زمینه ← ماشه: **M5 → M1** (پیشنهاد، همان ربات زنده)، M15 → M3، H1 → M5
  3. بازه: روزهای معاملاتی اخیر (برای M5 → M1: ۱، ۳، ۵ یا ۱۰ روز)
  4. ⏳ پیام انتظار با مرحله‌ی کار و زمان سپری‌شده، بعد نتیجه برای حساب ۱۰۰۰ دلاری با ریسک ۱٪ و ۲٪ هر معامله (مرکب)، فهرست معامله‌ها و نمودار موجودی
  - میان‌بر: `/backtest XAUUSD 5`

## بک‌تست
`bot/backtest.py` دقیقاً همان کد ربات زنده را روی داده‌ی گذشته اجرا می‌کند و روی داده‌ی یکسان، همان معامله‌ها را می‌دهد (تست شده). داده‌ی گذشته قیمت زنده ندارد، پس ترتیب داخل هر کندل M1 از شکل کندل گرفته می‌شود. بدون کمیسیون و لغزش قیمت؛ اسپرد در حد ضرر هست.
از خط فرمان با CSV کندل‌های M1 (`time,open,high,low,close`):
```bash
python -m bot.backtest XAUUSD --csv m1.csv --days 5 --balance 1000 --tf 5-1
```

## متغیرهای محیطی (Render → Environment)
| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از BotFather (ضروری) |
| `CHANNEL_ID` | اختیاری: کانال یا گروه برای هشدارها، مثلاً `@mychannel`. ربات باید ادمین باشد |
| `DATABASE_URL` | اختیاری: Postgres تا کاربران و فالوها با هر دیپلوی پاک نشوند |
| `SPREAD_<نماد>` | اسپرد بروکر به واحد قیمت، مثلاً `SPREAD_XAUUSD=0.25` یا `SPREAD_EURUSD=0.00012` |
| `ALERT_SETUPS` | پیام‌های همگانی. پیش‌فرض `TRADE,SPIKE`. اطلاعاتی: `H1,H2,L1,L2,WEDGE,PIN,WEDGE_BO,RANGE_BO` |
| `RR` | ریسک به ریوارد (پیش‌فرض `2`) |
| `ORDER_BARS` | اعتبار سفارش رنج / انتظار Key bar، به کندل M1 (پیش‌فرض `3`) |
| `LIVE_PRICES` | قیمت زنده برای سفارش‌ها و معامله‌ها (پیش‌فرض روشن؛ `0` برای خاموش) |
| `ALERT_CHARTS` | عکس همراه هر پیام (پیش‌فرض روشن؛ `0` برای خاموش) |
| `TIMEFRAME` / `TRIGGER_TF` | تایم‌فریم زمینه و ماشه (پیش‌فرض `5` و `1`) |
| `BARS` / `TRIGGER_BARS` | تعداد کندل M5 و M1 در هر بررسی (پیش‌فرض `500` و `300`) |
